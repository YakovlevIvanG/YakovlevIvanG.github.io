# Интерактивная эвтектическая фазовая диаграмма

Этот проект представляет собой интерактивную визуализацию простой бинарной эвтектической фазовой диаграммы, построенную на основе уравнения Шредера-ван Лаара.

**Попробовать в действии:** [Ссылка](https://yakovlevivang.github.io/)

### Возможности:
- Расчет линий ликвидуса в реальном времени
- Визуализация микроструктуры (первичные кристаллы + эвтектика)
- Настройка температур плавления и энтальпий компонентов

### Технологии:
- HTML5, CSS3
- JavaScript (библиотека p5.js для визуализации)
Собрано с применением Qwen 3.7Plus и GLM-5.3-Flash
